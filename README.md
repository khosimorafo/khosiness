# khosiness — Harness Engineering From Scratch

A first-principles Python agent harness.

The project will grow one architectural responsibility at a time:

1. task contracts
2. model adapters
3. event logging
4. the agent loop
5. tools
6. context engineering
7. repository navigation
8. shell sandboxing
9. policy and approvals
10. state and recovery
11. memory
12. context compaction
13. skills
14. subagents
15. evaluation
16. controlled harness improvement

The rule for the project is simple:

> The model proposes. The harness controls what is visible, executable,
> persistent, permitted and considered complete.
