Step 1 in context

What this step does

Turn an open-ended request into a bounded Task with an identity, objective, workspace, constraints, success criteria, and step limit.

What it builds on

Step 0 established that a task is not a conversation and that the harness, not the model, owns the work boundary.

Goal

Reject unusable inputs before any model call and make the intended finish condition explicit.

End state

A validated Task model, six tests, and ten benchmark templates exist. Templates still need a workspace before they are runnable Tasks.
