6. Stop short of a completeness claim
Two hits do not establish that every caller has been found. This possible subset even omits the actual call line. A result limit controls output size, not discovery order, total search time, or semantic completeness.
Report incomplete evidence honestly; narrow the search rather than claiming exhaustive coverage.

7. Reject an outside-workspace read
Resolving the proposed path places it outside the workspace. The existing containment check raises before a content read; the registry converts the error. The loop stores the failure as an observation and records its outcome. These are distinct responsibilities. Path checks still assume a stable workspace; they are not an OS sandbox.
Reject the operation, preserve the failure, and do not invent a missing result.

8. Grade the evidence, not the wording
Repository benchmarks should check expected facts and source evidence rather than an exact answer string. The Step 7 roadmap calls for 15 tasks; its older snapshot contains only three examples. Build and validate the full set during tutoring. Merely returning final text is not grading success.
