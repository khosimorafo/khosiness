2. Pass argv without shell parsing
With shell=False, subprocess receives a program and separate arguments. A semicolon inside a Python string remains part of that argument; no command shell interprets it. The chosen program still interprets its own flags and code.
Avoid shell parsing; still validate program identity and arguments.
Illustrative input / request

        "print('a; b')"]
shell = False

3. Reject cwd before launch
The reference checks the command basename against its allowlist and resolves cwd against the workspace. This example fails the cwd check. No subprocess is started on this path; the registry can convert the exception into a failed tool result.
A valid executable name does not make an outside cwd acceptable.

4. Choose the environment deliberately
The local snapshot passes only PATH and PYTHONUNBUFFERED. It reduces inherited variables but inherits PATH itself; it neither pins a trusted binary nor guarantees access to the project virtual environment. An inside cwd does not confine what the program can access.
Environment control and OS isolation are separate responsibilities.

5. Turn a zero exit into evidence
Assume the fixture test process returns successfully. The runner captures its exit code, streams, and elapsed duration. ShellTool marks the result ok only when the exit is zero and no timeout occurred. A passing test supports only what that test checks.
A process result is evidence; the harness still owns task completion.

6. Treat nonzero exit as data
A program may run normally and report failure through its exit code. The local runner returns that code rather than raising for it. ShellTool converts a nonzero result to ok=False so the loop can record and reason about the failure.
Do not confuse a failed check with a broken control loop.

7. Report a timeout explicitly
A long-running direct child exceeds the deadline. The reference catches TimeoutExpired and returns exit_code=None with timed_out=True. Python subprocess.run kills and waits for the direct child; this is not a promise that every descendant is gone.
Timeout is its own result, not an invented successful exit.

8. Know what the limits really bound
The reference keeps only the last 20,000 characters of each captured stream. Capture happens first, so this limits returned text, not peak memory. The local runner also lacks OS isolation and guaranteed descendant cleanup. Stronger execution infrastructure needs separate implementation and tests.
Do not promote a local runner into a security guarantee.
