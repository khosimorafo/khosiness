6. Reject an unknown skill
An unknown name raises KeyError in the reference loader. It does not return a structured tool error by itself. If exposed as a tool, a wrapper or registry must convert that exception to the desired failed result.
An exception boundary and a tool-result boundary are different.

7. Reject malformed front matter
The parser requires an opening delimiter, simple colon metadata lines, and a closing delimiter. It is deliberately small. Missing metadata keys or malformed files can fail catalog construction; validation and trusted input handling deserve stage tests.
A minimal parser is not a general YAML implementation.

8. Keep expertise and authority separate
The skill can improve the engineer’s debugging approach without adding a new tool or granting shell access. Retain the exact evidence and outcome of any later permitted test; a procedure is useful only when its reasoning survives verification.
Progressive disclosure adds knowledge, not authority.
