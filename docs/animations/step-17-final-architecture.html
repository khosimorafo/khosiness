5. Keep storage roles separate
RunState tracks the current run, the event store records facts, checkpoint helpers persist snapshots, and memory stores selected cross-run knowledge. Events do not automatically produce checkpoints or reusable memories.

6. Reject an unregistered capability
A read-only configuration can omit the shell tool. A proposed shell call then encounters an unknown tool in the registry and produces a failed result rather than acquiring process authority. This does not make existing filesystem tools an OS sandbox.
Unavailable capability must fail explicitly.
