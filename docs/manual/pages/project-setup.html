Setup

Project Setup

Create the repository, Python environment, package layout, test runner and first clean Git baseline before building any harness behavior.

← Overview 0. The Mental Model →

Why this step exists

You want the harness to grow inside a boring, repeatable Python project from the first minute. A clean baseline makes every later architectural change visible in Git and keeps the learning exercise focused on harness behavior rather than project housekeeping.

Files to create or modify

pyproject.tomlREADME.md.gitignoresrc/khosiness/__init__.pysrc/khosiness/cli.pytests/__init__.pybenchmarks/.gitkeep

Learning objectives

  • Create an installable Python package using the src/ layout.
  • Use an isolated virtual environment.
  • Run tests before any harness code exists.
  • Create a clean Git baseline that later steps can be compared against.
Repository/package/CLI naming: khosiness is the repository and Python package name. kness is the shorthand command name.

Implementation sequence

1

Create the repository

Start from an empty directory. Initialize Git immediately so every architectural step in this manual becomes inspectable history.

mkdir khosiness
cd khosiness
git init
2

Create and activate the Python environment

Use Python 3.12+ if practical. The exact environment manager is less important than keeping dependencies isolated and reproducible.

python -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
3

Create the initial project tree

mkdir -p src/khosiness tests benchmarks
touch src/khosiness/__init__.py
touch src/khosiness/cli.py
touch tests/__init__.py
touch benchmarks/.gitkeep
touch README.md .gitignore pyproject.toml
4

Define the package and development dependencies

Keep the first dependency set deliberately small. Pydantic is useful for structured contracts; pytest gives you the test harness you will use throughout the course.

5

Install the project in editable mode

python -m pip install -e ".[dev]"
6

Prove the baseline works

Run pytest even though you have no tests yet. Then verify that the package imports from the virtual environment.

pytest -q
python -c "import khosiness; print(khosiness.__file__)"
7

Create the baseline commit

git add .
git commit -m "chore: initialize harness project"

This is your known-clean starting point. Every later step should ideally end in another small, explainable commit.

# khosiness — Harness Engineering From Scratch

A first-principles Python agent harness built to understand:

- task contracts
- model adapters
- event logs
- agent loops
- tools
- context engineering
- sandboxing
- policy and approvals
- state and recovery
- memory
- skills
- subagents
- evaluation

The project begins deliberately small and grows one architectural
responsibility at a time.

Tests and checks

  • python --version reports the interpreter you expect.
  • python -m pip show khosiness shows the editable local package.
  • python -c "import khosiness" succeeds.
  • pytest -q runs successfully.
  • git status is clean after the baseline commit.
  • Run kness --version and confirm it prints khosiness 0.1.0.
Deliberate failure: deactivate the virtual environment and try the import from a shell where the package is not installed. Observe the difference between project source existing and the active Python environment knowing about it.

Common mistakes to watch for

  • Installing dependencies globally instead of using a project environment.
  • Starting with a large framework dependency set before you know which abstractions you need.
  • Skipping Git until “the real code” begins.
  • Creating many speculative packages and directories before their responsibilities exist.

Exit checklist

  • The package imports successfully from the active environment.
  • Pytest runs successfully.
  • The repository has the minimal project tree shown at right.
  • The baseline is committed and git status is clean.

Only now should you begin implementing harness concepts.

import argparse

from . import __version__


def main() -> None:
    parser = argparse.ArgumentParser(
        prog="kness",
        description="khosiness — personal agentic harness",
    )
    parser.add_argument(
        "--version",
        action="store_true",
        help="show the khosiness version",
    )
    args = parser.parse_args()

    if args.version:
        print(f"khosiness {__version__}")
        return

    parser.print_help()


if __name__ == "__main__":
    main()
