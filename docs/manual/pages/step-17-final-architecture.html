# First-Generation Harness Architecture

```text
Task
 |
 v
Agent Loop
 |----> Context Builder
 |         |----> Run State
 |         |----> Memory Retrieval
 |         `----> Skill Catalog
 |
 |----> Model Adapter
 |
 `----> Tool Registry
           |
           v
       Policy Gate
           |
           v
       Tool / Sandbox

Every meaningful transition
           |
           v
        Event Log
           |
           +----> Checkpoints
           `----> Evaluations
```

## Dependency direction

High-level orchestration depends on interfaces and data contracts.

Provider SDKs, shell execution, SQLite and filesystem details remain behind
their adapters.

## Core ownership

- Task owns the requested unit of work.
- ContextBuilder owns model-visible information selection.
- ModelAdapter owns provider translation.
- ToolRegistry owns capability discovery and dispatch.
- PolicyEngine owns deterministic authorization decisions.
- Sandbox owns process execution constraints.
- RunState owns current-run continuity.
- EventStore owns append-only factual history.
- MemoryStore owns selected cross-run knowledge.
- SkillLoader owns progressively disclosed procedures.
- SubagentSpawner owns bounded delegation.
- Evaluation code owns repeatable measurement.
docs/component-contracts.md complete file 
# Component Contracts

## Task
Validated objective, workspace, constraints, success criteria and step budget.

## ModelAdapter
Input: messages + tool schemas.
Output: provider-neutral ModelResponse.

## Tool
Input: validated structured arguments.
Output: ToolResult.
Tools never decide their own authorization policy.

## PolicyEngine
Input: Action.
Output: allow, ask or deny.

## Sandbox
Input: ExecRequest.
Output: ExecResult.
The sandbox owns timeout, cwd, environment and process boundaries.

## EventStore
Append-only storage of factual runtime transitions.

## RunState
Serializable state required to continue the current run.

## MemoryStore
Cross-run durable knowledge with explicit type, source and status.

## ContextBuilder
Selects a bounded subset of available information for the next model turn.

## SkillLoader
Discovers compact skill metadata and loads full procedures on demand.

## SubagentSpawner
Creates a child run with its own bounded objective, context and permissions.

## Eval Runner
Executes fixed benchmark tasks and produces comparable metrics.
