A first-principles build manual for constructing khosiness: a deeply personal agentic operating harness for one software engineer. Phase I builds the substrate; Part II evolves it into a continuously improving extension of the engineer. The shorthand/CLI name is kness.

How to use the khosiness manual

Phase I takes you from an empty Python repository to a measurable, recoverable agent harness. Work through it in order. Do not advance because the prose is finished; advance when the stage's code checkpoint, tests, trace inspection and exit criteria are all true.

Learning rule: type the important code yourself. The objective is to understand the mechanism well enough that you can later recognize it inside Codex, Claude Code, OpenHands, LangGraph or another harness.

# khosiness — Harness Engineering From Scratch

A first-principles Python agent harness built one responsibility at a time.

## System definition

A harness is a control system that repeatedly:

1. selects the context a model may see;
2. asks the model what to do next;
3. validates the proposed action;
4. executes only permitted actions;
5. records what happened;
6. updates durable run state;
7. repeats until the task is complete.

## Governing rule

The model proposes.

The harness decides:

- what context is visible;
- what tools exist;
- whether a proposed action is valid;
- whether an action requires approval;
- what actually executes;
- what is persisted;
- what is remembered across runs;
- when the task is considered complete.

## Version 0 scope

Version 0 will become a local, read-only repository assistant.

Initial capabilities:

- list directories;
- search text;
- read files.

Initial non-goals:

- file writes;
- shell execution;
- network access;
- persistent memory;
- subagents.

The project deliberately adds those capabilities only after the simpler
system can be observed and tested.

# Architecture — Stage 0

## The six planes

### 1. Cognition
The model reasons and proposes the next action.

### 2. Context
The harness decides what information reaches the model.

### 3. Action
Tools translate model requests into operations against the outside world.

### 4. Control
Policy, validation, budgets and approvals constrain actions.

### 5. Continuity
State, checkpoints, history and memory keep work coherent over time.

### 6. Measurement
Events, traces and evaluations reveal whether the system is reliable.

## First system boundary

```text
user task
   |
   v
harness
   |----> model
   |
   `----> read-only tools ----> workspace
```

The model never touches the workspace directly.

| tool validation | harness |
| tool execution | tool/runtime layer |
| permissions | harness policy |

from pathlib import Path

from pydantic import BaseModel, Field, field_validator


class Task(BaseModel):
    """A bounded unit of work executed by the harness."""

    id: str
    objective: str
    workspace: Path
    constraints: list[str] = Field(default_factory=list)
    success_criteria: list[str] = Field(default_factory=list)
    max_steps: int = 30

    @field_validator("objective")
    @classmethod
    def objective_must_not_be_blank(cls, value: str) -> str:
        value = value.strip()
        if not value:
            raise ValueError("objective must not be blank")
        return value

    @field_validator("workspace")
    @classmethod
    def workspace_must_exist(cls, value: Path) -> Path:
        value = value.expanduser().resolve()
        if not value.exists():
            raise ValueError(f"workspace does not exist: {value}")
        if not value.is_dir():
            raise ValueError(f"workspace is not a directory: {value}")
        return value

    @field_validator("max_steps")
    @classmethod
    def max_steps_must_be_positive(cls, value: int) -> int:
        if value < 1:
            raise ValueError("max_steps must be >= 1")
        return value

from pathlib import Path

import pytest

from khosiness.task import Task


def test_task_accepts_existing_workspace(tmp_path: Path):
    task = Task(
        id="task-1",
        objective="Find retry configuration",
        workspace=tmp_path,
        max_steps=5,
    )

    assert task.workspace == tmp_path.resolve()
    assert task.objective == "Find retry configuration"


def test_task_rejects_missing_workspace(tmp_path: Path):
    with pytest.raises(ValueError, match="workspace does not exist"):
        Task(
            id="task-1",
            objective="Find retry configuration",
            workspace=tmp_path / "missing",
        )


def test_task_rejects_file_as_workspace(tmp_path: Path):
    file_path = tmp_path / "not-a-directory"

            id="task-1",
            objective="x",
            workspace=file_path,

from pathlib import Path

from .events import Event


class JsonlEventStore:
    """Append-only JSON Lines event store."""

    def __init__(self, path: Path):
        self.path = path
        self.path.parent.mkdir(parents=True, exist_ok=True)

    def append(self, event: Event) -> None:
        with self.path.open("a", encoding="utf-8") as handle:
            handle.write(event.model_dump_json() + "\n")
            handle.flush()

    def load_all(self) -> list[Event]:
        if not self.path.exists():
            return []

        events: list[Event] = []
        with self.path.open("r", encoding="utf-8") as handle:
            for line in handle:
                line = line.strip()
                if line:
                    events.append(Event.model_validate_json(line))
        return events

from collections.abc import Callable

from .event_store import JsonlEventStore
from .events import Event
from .state import RunState
from .task import Task


def run(
    *,
    task: Task,
    state: RunState,
    model,
    context_builder,
    tools,
    events: JsonlEventStore,
    save_state: Callable[[RunState], None] | None = None,
) -> RunState:
    """Run the smallest genuine observe -> decide -> act loop."""

    save_state = save_state or (lambda _: None)

    while not state.finished and state.step < task.max_steps:
        state.step += 1
        messages = context_builder.build(task, state)

        events.append(
            Event(
                run_id=state.run_id,
                type="model_called",
                payload={"step": state.step},
            )
        )

        response = model.generate(
            messages=messages,
            tools=tools.schemas(),
        )

        events.append(
            Event(
                run_id=state.run_id,
                type="model_responded",
                payload={
                    "step": state.step,
                    "has_text": response.text is not None,
                    "tool_call_count": len(response.tool_calls),
                },
            )
        )

        if response.tool_calls:
            for call in response.tool_calls:
                events.append(
                    Event(
                        run_id=state.run_id,
                        type="tool_requested",
                        payload={
                            "name": call.name,
                            "arguments": call.arguments,
                        },
                    )
                )

                result = tools.execute(call)

                state.observations.append(
                    {
                        "tool": call.name,
                        "arguments": call.arguments,
                        "result": result.model_dump(),
                    }
                )

                events.append(
                    Event(
                        run_id=state.run_id,
                        type=(
                            "tool_completed"
                            if result.ok
                            else "tool_failed"
                        ),
                        payload={
                            "name": call.name,
                            "ok": result.ok,
                        },
                    )
                )

        elif response.text is not None:
            state.finished = True
            state.final_answer = response.text
            events.append(
                Event(
                    run_id=state.run_id,
                    type="task_completed",
                    payload={"step": state.step},
                )
            )

        save_state(state)

    if not state.finished and state.step >= task.max_steps:
        events.append(
            Event(
                run_id=state.run_id,
                type="step_limit_reached",
                payload={"max_steps": task.max_steps},
            )
        )

    return state

from khosiness.models.base import ToolCall

from .base import Tool, ToolResult


class ToolRegistry:
    def __init__(self):
        self._tools: dict[str, Tool] = {}

    def register(self, tool: Tool) -> None:
        if tool.name in self._tools:
            raise ValueError(f"duplicate tool: {tool.name}")
        self._tools[tool.name] = tool

    def schemas(self) -> list[dict]:
        return [tool.schema() for tool in self._tools.values()]

    def execute(self, call: ToolCall) -> ToolResult:
        tool = self._tools.get(call.name)

        if tool is None:
            return ToolResult(
                ok=False,
                content=f"Unknown tool: {call.name}",
            )

        try:
            return tool.execute(call.arguments)
        except Exception as exc:
            return ToolResult(
                ok=False,
                content=f"{type(exc).__name__}: {exc}",
            )

    name = "search_files"
    description = "Search UTF-8 text files inside the workspace."

    def __init__(self, workspace: Path):
        self.workspace = workspace.resolve()

    def schema(self) -> dict:
        return {
            "name": self.name,
            "description": self.description,
            "parameters": {
                "type": "object",
                "properties": {
                    "query": {"type": "string"},
                    "path": {"type": "string"},
                },
                "required": ["query", "path"],
            },
        }

    def execute(self, arguments: dict) -> ToolResult:
        root = safe_path(self.workspace, arguments["path"])
        query = arguments["query"]
        matches: list[str] = []

        for path in root.rglob("*"):
            if not path.is_file():
                continue
            try:
                lines = path.read_text(
                    encoding="utf-8"
                ).splitlines()
            except UnicodeDecodeError:
                continue

            for line_number, line in enumerate(lines, start=1):
                if query in line:
                    relative = path.relative_to(self.workspace)
                    matches.append(
                        f"{relative}:{line_number}:{line.strip()}"
                    )
                    if len(matches) >= 100:
                        return ToolResult(
                            ok=True,
                            content="\n".join(matches),
                            metadata={"truncated": True},
                        )

        return ToolResult(
            ok=True,
            content="\n".join(matches),
            metadata={"truncated": False},
        )

from dataclasses import dataclass

from khosiness.state import RunState
from khosiness.task import Task


@dataclass
class ContextStats:
    messages: int
    characters: int


class ContextBuilder:
    """Select what the model sees for the next decision."""

    def __init__(
        self,
        max_recent_observations: int = 8,
        max_observation_chars: int = 8_000,
    ):
        self.max_recent_observations = max_recent_observations
        self.max_observation_chars = max_observation_chars
        self.last_stats = ContextStats(messages=0, characters=0)

    def build(
        self,
        task: Task,
        state: RunState,
    ) -> list[dict]:
        recent = state.observations[
            -self.max_recent_observations:
        ]

        rendered_observations = []
        for observation in recent:
            text = repr(observation)
            if len(text) > self.max_observation_chars:
                text = (
                    text[: self.max_observation_chars]
                    + "... [truncated]"
                )
            rendered_observations.append(text)

        messages = [
            {
                "role": "system",
                "content": (
                    "You are operating inside a controlled harness. "
                    "Use tools to gather evidence. "
                    "Never invent tool results."
                ),
            },
            {
                "role": "user",
                "content": (
                    f"Objective: {task.objective}\n"
                    f"Constraints: {task.constraints}\n"
                    f"Success criteria: {task.success_criteria}\n"
                    f"Current step: {state.step}"
                ),
            },
            {
                "role": "user",
                "content": (
                    "Recent observations:\n"
                    + "\n".join(rendered_observations)
                ),
            },
        ]

        self.last_stats = ContextStats(
            messages=len(messages),
            characters=sum(
                len(message["content"])
                for message in messages
            ),
        )

        return messages

import os
import subprocess
import time
from pathlib import Path

from .base import ExecRequest, ExecResult


class LocalSandbox:
    """A constrained local runner used before introducing containers.

    It deliberately:
    - rejects commands outside an allowlist;
    - constrains cwd to the workspace;
    - uses shell=False;
    - passes a minimal environment;
    - bounds output;
    - enforces a timeout.
    """

    def __init__(
        self,
        workspace: Path,
        allowed_commands: set[str] | None = None,
    ):
        self.workspace = workspace.resolve()
        self.allowed_commands = allowed_commands or {
            "python",
            "pytest",
            "git",
            "ruff",
            "mypy",
            "grep",
            "find",
        }

    def execute(self, request: ExecRequest) -> ExecResult:
        if not request.argv:
            raise ValueError("argv must not be empty")

        command = Path(request.argv[0]).name
        if command not in self.allowed_commands:
            raise PermissionError(
                f"command is not allowed: {command}"
            )

        cwd = request.cwd.resolve()
        if not cwd.is_relative_to(self.workspace):
            raise PermissionError("cwd escapes workspace")

        started = time.perf_counter()

        try:
            process = subprocess.run(
                request.argv,
                cwd=cwd,
                text=True,
                capture_output=True,
                timeout=request.timeout_seconds,
                shell=False,
                env={
                    "PATH": os.environ.get("PATH", ""),
                    "PYTHONUNBUFFERED": "1",
                },
            )
            return ExecResult(
                exit_code=process.returncode,
                stdout=process.stdout[-20_000:],
                stderr=process.stderr[-20_000:],
                duration_ms=int(
                    (time.perf_counter() - started) * 1000
                ),
            )
        except subprocess.TimeoutExpired as exc:
            return ExecResult(
                exit_code=None,
                stdout=(exc.stdout or "")[-20_000:]
                if isinstance(exc.stdout, str)
                else "",
                stderr=(exc.stderr or "")[-20_000:]
                if isinstance(exc.stderr, str)
                else "",
                duration_ms=int(
                    (time.perf_counter() - started) * 1000
                ),
                timed_out=True,
            )

import sqlite3
from pathlib import Path

from .schema import Memory


SCHEMA = """
CREATE TABLE IF NOT EXISTS memories (
    id TEXT PRIMARY KEY,
    memory_type TEXT NOT NULL,
    content TEXT NOT NULL,
    source_run_id TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    status TEXT NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_memories_type
ON memories(memory_type);
"""


class SqliteMemoryStore:
    def __init__(self, path: Path):
        self.path = path
        self.path.parent.mkdir(
            parents=True,
            exist_ok=True,
        )
        with self._connect() as connection:
            connection.executescript(SCHEMA)

    def _connect(self):
        return sqlite3.connect(self.path)

    def add(self, memory: Memory) -> None:
        with self._connect() as connection:
            connection.execute(
                """
                INSERT INTO memories (
                    id,
                    memory_type,
                    content,
                    source_run_id,
                    created_at,
                    updated_at,
                    status
                ) VALUES (?, ?, ?, ?, ?, ?, ?)
                """,
                (
                    memory.id,
                    memory.memory_type,
                    memory.content,
                    memory.source_run_id,
                    memory.created_at.isoformat(),
                    memory.updated_at.isoformat(),
                    memory.status,
                ),
            )

    def set_status(
        self,
        memory_id: str,
        status: str,
    ) -> None:
        with self._connect() as connection:
            connection.execute(
                """
                UPDATE memories
                SET status = ?
                WHERE id = ?
                """,
                (status, memory_id),
            )

    def search(
        self,
        query: str,
        memory_types: list[str] | None = None,
        limit: int = 5,
    ) -> list[Memory]:
        clauses = [
            "status = 'active'",
            "content LIKE ?",
        ]
        parameters: list[object] = [
            f"%{query}%"
        ]

        if memory_types:
            placeholders = ",".join(
                "?" for _ in memory_types
            )
            clauses.append(
                f"memory_type IN ({placeholders})"
            )
            parameters.extend(memory_types)

        parameters.append(limit)

        sql = f"""
            SELECT
                id,
                memory_type,
                content,
                source_run_id,
                created_at,
                updated_at,
                status
            FROM memories
            WHERE {" AND ".join(clauses)}
            ORDER BY updated_at DESC
            LIMIT ?
        """

        with self._connect() as connection:
            rows = connection.execute(
                sql,
                parameters,
            ).fetchall()

        return [
            Memory(
                id=row[0],
                memory_type=row[1],
                content=row[2],
                source_run_id=row[3],
                created_at=row[4],
                updated_at=row[5],
                status=row[6],
            )
            for row in rows
        ]

from pydantic import BaseModel, Field

from khosiness.state import RunState


class Compaction(BaseModel):
    through_step: int
    summary: str
    decisions: list[str] = Field(
        default_factory=list
    )
    evidence: list[str] = Field(
        default_factory=list
    )
    unresolved: list[str] = Field(
        default_factory=list
    )


def should_compact(
    *,
    context_characters: int,
    threshold: int = 60_000,
) -> bool:
    return context_characters > threshold


def deterministic_compact(
    state: RunState,
    keep_recent: int = 6,
) -> tuple[Compaction, list[dict]]:
    """A deliberately simple compactor for learning.

    It preserves recent observations verbatim and records how
    many older observations were summarized. Later you can
    replace the summary strategy with a model-assisted one.
    """

    if keep_recent < 1:
        raise ValueError(
            "keep_recent must be >= 1"
        )

    old = state.observations[:-keep_recent]
    recent = state.observations[-keep_recent:]

    compaction = Compaction(
        through_step=state.step,
        summary=(
            f"{len(old)} older observations "
            "were compacted. Inspect the event log "
            "for the original evidence."
        ),
        decisions=list(state.completed_work),
        evidence=[
            observation["tool"]
            for observation in old
            if "tool" in observation
        ],
        unresolved=list(state.pending_actions),
    )

    return compaction, recent

def parse_front_matter(
    text: str,
) -> tuple[dict[str, str], str]:
    lines = text.splitlines()

    if not lines or lines[0].strip() != "---":
        raise ValueError(
            "skill must start with YAML-like front matter"
        )

    metadata: dict[str, str] = {}
    closing_index = None

    for index, line in enumerate(
        lines[1:],
        start=1,
    ):
        if line.strip() == "---":
            closing_index = index
            break

        if ":" not in line:
            raise ValueError(
                f"invalid metadata line: {line}"
            )

        key, value = line.split(":", 1)
        metadata[key.strip()] = value.strip()

    if closing_index is None:
        raise ValueError(
            "front matter is not closed"
        )

    body = "\n".join(
        lines[closing_index + 1:]
    ).strip()

    return metadata, body


class SkillLoader:
    def __init__(self, skills_dir: Path):
        self.skills_dir = skills_dir.resolve()

    def catalog(self) -> list[SkillSummary]:
        summaries = []

        for path in sorted(
            self.skills_dir.glob("*/SKILL.md")
        ):
            metadata, _ = parse_front_matter(
                path.read_text(encoding="utf-8")
            )
            summaries.append(
                SkillSummary(
                    name=metadata["name"],
                    description=metadata[
                        "description"
                    ],
                    path=path,
                )
            )

        return summaries

    def load(self, name: str) -> str:
        for summary in self.catalog():
            if summary.name == name:
                _, body = parse_front_matter(
                    summary.path.read_text(
                        encoding="utf-8"
                    )
                )
                return body

        raise KeyError(f"unknown skill: {name}")

class SubagentSpawner:

        self,
        child_runner: Callable[
            [AgentRequest, str],

        ],

        self,
        request: AgentRequest,

        child_run_id = f"child-{uuid4()}"

            request,
            child_run_id,

19. Building the Personal Harness

Phase I gives khosiness a safe, observable and testable substrate. Part II turns that substrate into a deeply personal engineering operating harness that reflects, augments and iteratively improves one engineer.

← 18. 12-Week Build Plan Overview →
The destination

What khosiness is becoming

khosiness is a continuously evolving computational extension of one software engineer: preserving context, amplifying capability, extending operational reach, improving the engineer's own skills, and progressively earning authority to act.

Single-user is a design advantage. khosiness does not need to generalize to millions of users. It can become specific to one engineer's judgment, projects, working habits, technical standards, recurring mistakes, ambitions and risk tolerance.

The optimization target changes

Phase I mostly optimizes the reliability of the harness. Part II optimizes the combined system:

Engineer + khosiness

The objective is no longer simply “finish the task faster.” It becomes:

maximize:
    long-term engineer capability
    × effective work reach
    × quality
    × reliability

subject to:
    safety
    authority
    cost
    attention
    reversibility

The two fundamental learning loops

                KHOSI

      WORK REACH LOOP
      Understand → Plan → Act
      → Observe → Verify → Report → Learn

                  ↓ traces + outcomes

      ENGINEER LOOP
      Observe Khosi → Diagnose
      → Teach → Challenge → Measure → Adapt

                  ↓

          better Engineer + greater reach

The first loop makes khosiness better at getting work done. The second prevents automation from quietly weakening the engineer. Sometimes khosiness should act; sometimes it should collaborate; sometimes it should deliberately leave the cognitive work with the engineer so skill compounds rather than decays.

The three collaboration modes

ModePurposeTypical use
Learning Maximize the engineer's understanding and capability. New architecture concepts, unfamiliar systems, deliberate practice.
Collaboration Engineer and khosiness divide the reasoning and execution. Architecture, debugging, design reviews, complex project work.
Execution Optimize for reliable completion within an established envelope. Routine tests, maintenance, monitoring, known procedures.

The five post-Phase-I development arcs

Phase II-A — Personalize khosiness

  • engineering principles and working philosophy;
  • observed strengths and weaknesses;
  • recurring mistakes and blind spots;
  • preferred decomposition and verification styles;
  • communication and documentation habits;
  • project-specific and cross-project memory.

Phase II-B — Extend khosiness

  • coding and repository operations;
  • architecture and design;
  • research and technical synthesis;
  • documentation and communication;
  • infrastructure and operational work;
  • project coordination and continuous monitoring.

Phase II-C — Model the Engineer

  • build an evidence-based engineering profile;
  • distinguish self-belief from observed performance;
  • identify areas where khosiness repeatedly compensates;
  • turn recurring weakness into learning interventions;
  • measure whether the engineer is actually improving.

Phase II-D — Earn trust

  • track success, reversions and human corrections per capability;
  • grant autonomy by capability rather than globally;
  • define reversible and irreversible action classes;
  • use approval history and evaluation evidence to change authority;
  • keep production-critical actions narrow until evidence justifies expansion.

Phase II-E — Let khosiness drive bounded objectives

  • continuous planning and execution inside known limits;
  • delegation to subagents;
  • monitoring and recovery;
  • escalation only when genuine judgment is needed;
  • long-horizon operation while preserving inspectability and control.

The autonomy ladder

LevelNameMeaning
L0ObserveReads, watches and explains.
L1AdviseRecommends actions but does not prepare execution.
L2PrepareCreates patches, plans or actions and waits.
L3Execute with approvalActs only after explicit authorization.
L4Execute by policyActs automatically inside established safe envelopes.
L5Drive bounded objectivesPlans and operates over extended periods, escalating only what exceeds its mandate.
Autonomy is earned per capability. khosiness may eventually be L4 for routine dependency updates while remaining L1 for production database migrations.

Metacognition

Eventually, khosiness should reason about the operating system formed by you and it together.

  • Where do you repeatedly need help?
  • Which tasks are consistently underestimated?
  • Where do you abstract too early?
  • Which verification patterns reduce redesign?
  • Where does delegation improve throughput without reducing understanding?
  • Which capabilities should khosiness return to you for deliberate practice?
These are not merely memories. They are observations about the performance of the combined Engineer + khosiness system.

The Khosiness Constitution

Before adding deep personalization or autonomy, define the governing specification that says what khosiness exists to optimize, what it must never optimize away, how it relates to you, how it may learn about you, and how authority is earned.

The Constitution should eventually answer at least:

  • What is khosiness for?
  • What must remain under human judgment?
  • When should khosiness optimize for execution versus learning?
  • What kinds of personal observations may become durable memory?
  • How can memory be challenged or corrected?
  • How is capability-specific trust measured?
  • How does autonomy increase, decrease or get revoked?
  • What classes of action always require explicit approval?
  • How does khosiness preserve the engineer's own capability?
Do not jump directly from Step 18 to “fully autonomous.” The Constitution, personal model and evidence-based trust system are the bridge between a useful harness and a system that can safely drive.
